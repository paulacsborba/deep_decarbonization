# Deep decarbonization model

Calliope model and data for exploring climate impacts, land-use constraints, and near-optimal adaptation pathways in Brazil’s energy system.

This repository contains the Calliope model, input data, scenario configurations, and analysis scripts developed for the paper on climate change impacts and adaptation in Brazil’s decarbonized energy system. 

The study explores six core scenarios combining two land-use regimes: Technical Potential and Conservation, with three climate conditions: no climate change, SSP2–4.5, and SSP5–8.5. 

Climate-related changes in hydropower, onshore wind, and solar resources are incorporated into a spatially explicit, sector-coupled energy system model. Near-optimal solutions generated using SPORES are used to investigate technological and spatial flexibility, infrastructure reallocation, system costs, and robust adaptation strategies.
